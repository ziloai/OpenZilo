API index¶

Device applicability

This document applies to OpenZilo Q.

The public API is defined by openzilo.__all__. Import it with import openzilo as sdk; underscore-prefixed modules are private. Start with the quick start; returned fields are listed in data types.

Find APIs by task¶

Task Common APIs Purpose
Connection scan_rings(), connect_ring(), OpenZiloClient Scan, connect, send requests, and await events.
Device information get_system_info(), parse_system_info() Firmware, time, storage, battery, serial number, CPUID and model.
Feature discovery get_device_capabilities(), DeviceCapabilities.supports() Check supported features, interface versions and parameter limits.
Remote recording start_audio_recording(), stop_audio_recording(), set_audio_recording_config() Start, stop and configure recordings.
Time synchronization enable_time_sync(), send_time_response() Reply automatically or manually to device 0x0401 with 0x0402.
IMU and events start_sensor_report(), wait_sensor_data(), wait_sensor_double_tap_event() Receive IMU batches, taps and button events.
Logs get_log_storage(), read_log_chunk() Inspect log storage and read chunks by offset.
Recording transfers receive_auto_audio_file(), receive_live_audio_file(), download_audio_file() Receive completed or live recordings, or download a stored file.
Decode and save save_audio_bundle(), decode_audio_to_wav() Preserve raw audio and create WAV.
Protocol utilities encode_packet(), decode_packet(), PacketStream Inspect packets, CRC and binary fields.

Connection and system¶

Function Signature Returns Usage
scan_rings() await scan_rings(address=None, timeout_s=25.0) list[BleDeviceInfo] Scan BLE devices, optionally filtering by address.
connect_ring() await connect_ring(address=..., command_timeout_s=10.0, auto_time_sync=False) OpenZiloClient Create and connect a client; the caller must disconnect it.
get_system_info() await get_system_info(client, timeout_s=None) SystemInfo Read device information.
parse_system_info() parse_system_info(body) SystemInfo Parse a 0x0102 body, normally for tests or protocol debugging.
enable_time_sync() enable_time_sync(client) None Register an automatic responder for 0x0401.
send_time_response() await send_time_response(client, request_time, response_time=None, send_time=None) None Send a manual 0x0402 time response.
get_log_storage() await get_log_storage(client, timeout_s=None) LogStorageInfo Read log storage information.
read_log_chunk() await read_log_chunk(client, index, offset, size, timeout_s=None) bytes Read log bytes by index, offset and length.

Feature discovery¶

API Returns Description
await get_device_capabilities(client, timeout_s=None, refresh=False) DeviceCapabilities Query supported features and recording parameter ranges.
capabilities.supports(name, major=None, min_minor=0) bool Check a feature and its interface version.
get_sdk_identity() SdkIdentity Return the SDK version and source checksum for environment records.

Feature discovery results are cleared on disconnect. See compatibility for fields.

Remote recording¶

API Purpose
get_audio_recording_config() / set_audio_recording_config() Requires firmware V2.001.0002.0001 or later. Read or change recording configuration.
start_audio_recording() Requires firmware V2.001.0002.0001 or later. Start recording and return its session ID.
stop_audio_recording() Requires firmware V2.001.0002.0001 or later. Stop early or cancel the specified recording.
get_audio_recording_status() Requires firmware V2.001.0002.0001 or later. Query recording state and the saved file.
wait_audio_recording_finished() Requires firmware V2.001.0002.0001 or later. Wait for recording and saving to finish.

These APIs are asynchronous. Arguments, results and complete examples are in recording control.

Firmware updates¶

Function Call Returns Description
update_firmware() await update_firmware(client, firmware, version=..., sha256=..., expected_model=..., progress=..., timeout_s=30, total_timeout_s=600, reboot_timeout_s=90) SystemInfo Upload an official application package, wait for reboot, and verify the running version. See firmware updates.
