--8<-- "docs/_includes/features.zh-CN.md:user-guide-scope"

同一种颜色可能有不同含义，请结合刚执行的操作与亮灭节奏判断。

| 场景 | 灯光表现 | 含义／下一步 |
| --- | --- | --- |
| 启动／复位 | 白灯亮约 0.2 秒 | 戒指已开始启动，不代表蓝牙已连接。 |
| 正在充电 | 红灯约亮 0.5 秒、灭 0.5 秒 | 正在充电。 |
| 充电完成 | 充满状态持续期间绿灯常亮 | 充电完成。 |
| 正在录音 | 绿灯常亮 | 正在录音，松开按键结束。 |
| `V2.001.0002.0000` 模式切换成功 | 蓝灯闪两次，约亮 0.5 秒、灭 0.5 秒 | 录音／手势模式已切换，两个方向使用相同提示。 |
| 录音传输中 | 蓝灯约亮 0.5 秒、灭 0.5 秒 | 正在传输录音。 |
| 录音或 IMU 启动失败 | 红灯快闪三次，约亮 0.1 秒、灭 0.1 秒 | 操作失败，请检查电量、存储空间与当前模式。 |
| 低电量提示 | 红灯持续亮约 2 秒后熄灭 | 请充电。电量低时短按可触发此提示。 |
| 严重低电量提示 | 红灯短亮约 0.3 秒后熄灭 | 请先充电；仅凭该提示不能确认设备已关机。 |

低电量和严重低电量提示是**持续亮红灯一段时间**，不是闪三次。启动、模式切换和错误提示持续时间较短，可能错过。

不同灯光提示可能互相打断，低电量提示优先。录音和充满电都显示绿灯，需要结合刚才的操作判断。录音或传输结束后，如果设备仍在充电，可能继续显示充电灯光。

参见[按键与模式](https://github.com/ziloai/OpenZilo/wiki/Buttons-and-Modes-zh-CN)与[首次使用](https://github.com/ziloai/OpenZilo/wiki/First-Use-zh-CN)。

固件 `V2.001.0002.0001` 已取消录音／手势模式切换，不再用该蓝灯提示判断模式。
